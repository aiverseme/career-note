# 커리어 노트

강사의 커리어(강의·프로젝트·수상·연수 기록)를 중심으로 일정, 아들 일정, 가계부까지 한곳에서 관리하는 개인 웹앱입니다.

## 기능
- **오늘**: 오늘 일정, 오늘의 이슈, 앞으로 2주, 결제 예정, 올해 커리어 요약
- **일정**: 수업·학습·업무·개인·성빈·이슈·결제일 달력 (분류별 켜기/끄기)
- **커리어**: 기록 목록 / 이력서(텍스트 복사·인쇄) / 포트폴리오(프로젝트·업적·기관·연도별 묶기)
- **가계부**: 지출 입력, 분류별 합계, 정기 결제(학원비 등) 납부 처리
- **설정**: 이력서 머리글, 백업 내보내기·가져오기

## 파일 구조
| 파일 | 하는 일 |
|---|---|
| `index.html` | 뼈대 — 메뉴와 빈 화면 칸 |
| `css/style.css` | 디자인 — 맨 위 색 변수만 바꾸면 전체 색 변경 |
| `js/store.js` | 데이터 창고 — 저장·불러오기 (다음 단계: Supabase로 교체) |
| `js/app.js` | 화면 그리기와 버튼 동작 |
